# Changelog

All notable changes to AirClick are documented in this file.

## [1.0.0] - 2026-10-10

### Added

- Two-hand mouse control using a webcam and MediaPipe hand tracking.
- Mouse movement, drag, left/right/middle click, double-click, and scroll gestures.
- Gesture stabilization, pause/resume controls, and an on-screen help overlay.
- Windows installer with Start Menu and desktop shortcuts, plus an uninstaller.
- Optional, size-limited application logs with a first-run consent prompt.
- Persian setup instructions, privacy information, and a release checklist.
