# AirClick Pro

کنترل حرفه‌ای موس با دو دست — وب‌کم + MediaPipe + PyAutoGUI

## اجرا

```bash
pip install -r requirements.txt
python main.py
```

> در اولین اجرا، مدل MediaPipe (`hand_landmarker.task`) به‌صورت خودکار دانلود می‌شود.

## سیستم موردنیاز

- سیستم‌عامل رسمی: Windows 11 نسخه‌ی 64 بیتی (x64).
- Windows 10 نسخه‌ی 22H2 و 64 بیتی ممکن است اجرا شود، اما فقط به‌صورت
  best-effort پشتیبانی می‌شود و روی آن تضمینی نداریم. پشتیبانی عادی Windows 10
  در 14 اکتبر 2025 پایان یافته است؛ [اطلاعات چرخه‌ی عمر Windows 10 در Microsoft](https://learn.microsoft.com/en-us/lifecycle/products/windows-10-home-and-pro).
- وب‌کم فعال با وضوح پیشنهادی حداقل 640×480 و اجازه‌ی دسترسی دوربین در Windows.
- برای نسخه‌ی Setup، نصب‌کننده برای نصب در Program Files به تأیید Administrator
  نیاز دارد؛ اجرای روزمره‌ی خود AirClick باید از حساب کاربری عادی ممکن باشد.
- به نصب Python برای استفاده از نسخه‌ی Setup نیازی نیست.
- مدل تشخیص دست داخل Setup قرار دارد؛ اجرای نسخه‌ی نصب‌شده برای تشخیص دست به
  اتصال اینترنت نیاز ندارد.

برای ساخت قابل‌تکرار روی Windows x64، از Python 3.14.7 و فایل نسخه‌های قفل‌شده
استفاده کنید:

```powershell
python -m pip install -r requirements-lock.txt
```

## حریم خصوصی و امنیت

- AirClick برای تشخیص دست از دوربین دستگاه استفاده می‌کند.
- پردازش تصویر به‌صورت محلی روی همان دستگاه انجام می‌شود.
- تصویر دوربین، فریم‌ها و اطلاعات دست به سرور AirClick ارسال نمی‌شوند.
- تصویر دوربین در فایل ذخیره نمی‌شود.
- مدل `hand_landmarker.task` در نسخه‌ی Setup همراه برنامه ارائه می‌شود. در اجرای
  نسخه‌ی سورس، اگر مدل در ریشه‌ی پروژه موجود نباشد، برنامه آن را از منبع رسمی
  MediaPipe دانلود می‌کند.
- ذخیره‌ی لاگ اختیاری است و برنامه در اولین اجرا برای فعال‌کردن آن اجازه می‌گیرد.
  لاگ شامل تصویر دوربین نیست و اندازه‌ی آن به حداکثر ۵۱۲ کیلوبایت محدود می‌شود.
- در صورت فعال‌کردن لاگ، فایل آن در پوشه‌ی `logs` کنار برنامه‌ی نصب‌شده ذخیره
  می‌شود. تنظیم رضایت در `%LOCALAPPDATA%\AirClick\preferences.json` نگهداری
  می‌شود.
- برای استفاده از برنامه باید اجازه‌ی دسترسی به دوربین را در Windows فعال کنید.

## تست

تاریخچه‌ی تغییرات هر نسخه در [CHANGELOG.md](CHANGELOG.md) ثبت می‌شود.

```bash
python test_setup.py
python tests/test_gestures.py
python tests/test_hand_tracker.py
python tests/test_mouse_controller.py
python tests/test_settings.py
```

`test_setup.py` تنظیمات، وابستگی‌ها، دوربین و مدل MediaPipe را بررسی می‌کند.

اندازه‌ی لاگ برای جلوگیری از مصرف فضای دیسک به‌صورت خودکار محدود می‌ماند.
در اولین اجرا برای ذخیره سابقه از کاربر اجازه گرفته می‌شود؛ با انتخاب «خیر»
هیچ فایل لاگی ساخته نمی‌شود. در نسخه نصب‌شده، در صورت موافقت، لاگ کنار فایل
اجرایی برنامه و در پوشه‌ی `logs` ذخیره می‌شود؛ در اجرای نسخه‌ی سورس، لاگ در
پوشه‌ی `logs` ریشه‌ی پروژه قرار می‌گیرد.
Setup برای این پوشه مجوز نوشتن کاربر فعلی را تنظیم می‌کند تا اجرای عادی
برنامه به دسترسی Administrator نیاز نداشته باشد.
هنگام حذف برنامه، پوشه لاگ و انتخاب رضایت ذخیره‌شده نیز حذف می‌شوند؛ بنابراین
نصب بعدی مانند نصب تازه شروع می‌شود.

## رفع خطاهای رایج

### برنامه دوربین را پیدا نمی‌کند یا می‌گوید دوربین در حال استفاده است

- برنامه‌هایی مثل Camera، Teams، Zoom و مرورگر را که ممکن است دوربین را گرفته
  باشند ببند و AirClick را دوباره اجرا کن.
- در Windows، از **Settings → Privacy & security → Camera** مطمئن شو دسترسی
  دوربین برای برنامه‌های دسکتاپ فعال است.
- دوربین را با برنامه‌ی Windows Camera امتحان کن. اگر آن هم تصویر ندارد،
  اتصال وب‌کم یا درایورش را بررسی کن.
- AirClick به‌طور پیش‌فرض دوربین شماره‌ی 0 را باز می‌کند و در رابط کاربری
  انتخاب دوربین دیگری ندارد.

### پیام اجازه‌ی ذخیره‌ی لاگ دوباره نمایش داده نمی‌شود

انتخاب قبلی در `%LOCALAPPDATA%\AirClick\preferences.json` ذخیره می‌شود؛ بنابراین
نمایش ندادن دوباره‌ی پیام پس از انتخاب «بله» یا «خیر» طبیعی است. برای شروع دوباره
با انتخاب تازه، AirClick را از مسیر Uninstall حذف و مجدداً نصب کن؛ Uninstaller
انتخاب رضایت و لاگ برنامه را هم پاک می‌کند.

### برنامه اجرا نمی‌شود یا موتور تشخیص دست راه‌اندازی نمی‌شود

- Setup رسمی مدل تشخیص دست را همراه برنامه نصب می‌کند و به اینترنت نیاز ندارد.
  اگر خطای مدل یا MediaPipe دیدی، برنامه را حذف و Setup را دوباره نصب کن؛
  فایل‌های پوشه‌ی نصب را دستی پاک نکن.
- اگر نسخه‌ی سورس را اجرا می‌کنی و `hand_landmarker.task` موجود نیست، اتصال
  اینترنت را بررسی کن؛ برنامه برای دریافت مدل از اینترنت استفاده می‌کند.
- اگر مشکل ادامه داشت، نسخه‌ی Windows، متن کامل خطا و در صورت فعال بودن،
  فایل `logs\airclick.log` کنار برنامه‌ی نصب‌شده را برای پشتیبانی بفرست.

### نصب یا حذف برنامه با مشکل روبه‌رو شده است

- برای نصب در مسیر پیش‌فرض `Program Files`، درخواست Administrator ویندوز را
  تأیید کن؛ خود برنامه را پس از نصب از Shortcut عادی اجرا کن.
- برای حذف، از **Start → AirClick → Uninstall AirClick** یا
  **Settings → Apps → Installed apps → AirClick → Uninstall** استفاده کن.
- فولدر نصب را دستی پاک نکن؛ این کار فایل‌های لازم برای حذف را از بین می‌برد.
  اگر Uninstall خطا داد، متن یا تصویر کامل خطا را برای پشتیبانی بفرست.

## ژست‌ها

> AirClick ورودی‌های واقعی موس را انجام می‌دهد. پیش از استفاده، دست کلیک را در
> حالت آماده نگه دار و ژست‌ها را ابتدا روی محتوای غیرحساس امتحان کن. برای توقف
> فوری کنترل موس، `p` را بزن؛ برای خروج، `q` یا `Esc` را فشار بده.

| دست | ژست | عمل |
|-----|-----|-----|
| موس | ☝️ فقط اشاره | حرکت موس |
| موس | ✌️ اشاره+وسط | Drag |
| کلیک | 👇 اشاره پایین | کلیک چپ |
| کلیک | 🖕 وسط پایین | کلیک راست |
| کلیک | ✊ مشت | کلیک وسط |
| کلیک | ✌️↓ اشاره+وسط پایین | دابل کلیک |
| کلیک | 💍 حلقه پایین | اسکرول |

## کلیدها

- `q` — خروج
- `h` — راهنما
- `d` — دیباگ
- `p` — توقف/ادامه کنترل موس (Pause)

با زدن `d`، پنل دیباگ میانگین لغزان دوثانیه‌ای زمان خواندن دوربین، استنتاج
مدل دست، منطق برنامه و رندر تصویر را بر حسب میلی‌ثانیه نشان می‌دهد تا منشأ
افت سرعت مشخص شود.

## تنظیم حساسیت

مقادیر قابل تنظیم در `config/settings.py` قرار دارند:

- `MOUSE_SETTINGS.movement_speed` — سرعت حرکت موس
- `MOUSE_SETTINGS.smoothing_factor` — نرمی حرکت، بین `0` و `1`
- `MOUSE_SETTINGS.dead_zone` — مقدار حرکت نادیده‌گرفته‌شده برای کاهش لرزش
- `MOUSE_SETTINGS.gesture_stability_frames` — تعداد فریم لازم برای تأیید ژست
- `HAND_SETTINGS.role_stability_frames` — تعداد فریم لازم برای تغییر نقش دست
- `HAND_SETTINGS.min_hand_separation` — حداقل فاصله دو دست

مقادیر نامعتبر هنگام شروع برنامه با خطای واضح رد می‌شوند.

## ساخت Setup ویندوز

برای ساخت فایل اجرایی مستقل و نصب‌کننده شبیه برنامه‌های ویندوز:

1. Python `3.14.7` نسخه‌ی 64 بیتی و [Inno Setup](https://jrsoftware.org/isinfo.php) را نصب کن.
2. PowerShell را در ریشه‌ی پروژه باز کن و محیط Build مستقل را بساز:

```powershell
python --version
python -m venv .release-venv
$env:PYTHONPATH = ''
$env:PIP_CONFIG_FILE = 'NUL'
& .\.release-venv\Scripts\python.exe -m pip --isolated install -r .\requirements-lock.txt
if ($LASTEXITCODE -ne 0) { throw "Dependency installation failed." }
.\packaging\build_installer.ps1
```

اسکریپت Build فقط از `.release-venv` استفاده می‌کند و نسخه‌ی Python را بررسی
می‌کند. برای ساخت فقط نسخه‌ی اجرایی بدون نصب‌کننده، دستور آخر را این‌طور اجرا کن:

```powershell
.\packaging\build_installer.ps1 -SkipInstaller
```

نسخه‌ی برنامه را فقط در `config/version.py` تغییر بده؛ شماره‌ی نسخه و نام
فایل Setup از همان مقدار در Build گرفته می‌شود. فایل نصب با قالب
`dist/installer/AirClick-Setup-<version>.exe` ساخته می‌شود.

## حذف برنامه در Windows

در Setup می‌توان مسیر نصب را در صفحه‌ی **Select Destination Location** انتخاب
یا تغییر داد؛ هنگام نصب مجدد، مسیر نصب فعلی به‌صورت پیش‌فرض پیشنهاد می‌شود.

پس از نصب، AirClick را از یکی از این مسیرها حذف کن:

- منوی Start: پوشه‌ی **AirClick** → **Uninstall AirClick**
- **Settings → Apps → Installed apps** → **AirClick** → **Uninstall**

پوشه‌ی نصب را پیش از اجرای Uninstaller دستی حذف نکن؛ فایل‌های Uninstaller و
اطلاعات حذف داخل همان پوشه قرار دارند.
